# 04 · 云端构建（GitHub Actions + GameCI）

> 用途：不在本机装 Unity，也能产出可安装的 Android APK。
> 工作流：[build-android.yml](../.github/workflows/build-android.yml)、[unity-activation.yml](../.github/workflows/unity-activation.yml)

---

## 1. 前置

- 仓库推到 **GitHub**（私有也可以，Actions 分钟数有限额）。
- 仓库 Settings → Actions → General → 允许运行工作流。
- 只有一个 Unity 许可证来源需要配置，见下。

---

## 2. 第一次：获取 Unity 许可证

1. 打开 GitHub → Actions → `Unity License Activation` → `Run workflow`。
2. 跑完后下载 artifact `unity-activation-file`，得到 `.alf` 文件。
3. 打开 https://license.unity3d.com/manual ，上传 `.alf`，登录你的 Unity 账号。
4. 选择 **Unity Personal**（或你的 Pro 席位），下载 `.ulf` 文件。
5. 仓库 Settings → Secrets and variables → Actions → New repository secret：

| Secret | 内容 | 必填 |
|---|---|---|
| `UNITY_LICENSE` | `.ulf` 文件的完整文本 | 是 |
| `UNITY_EMAIL` | Unity 账号邮箱 | 建议 |
| `UNITY_PASSWORD` | Unity 账号密码 | 建议 |

> 账号开了 2FA 时，`UNITY_EMAIL/PASSWORD` 可能无法自动激活，以 `UNITY_LICENSE` 为准。
> 许可证与 Unity 版本绑定；升级 Unity 后需要重新生成 `.ulf`。

---

## 3. 触发构建

推送到 `main` / `master`，或在 Actions 里手动 `Run workflow`。

流程：

```
EditMode 单测（9 个） → 通过后 → Build APK → 上传 artifact
```

成功后下载 artifact **`android-apk`**，里面是 `tarkovlike.apk`（debug 签名，可直接安装）。

安装：手机允许「未知来源」，或 `adb install -r tarkovlike.apk`。

---

## 4. 真机预期结果

启动后屏幕直接显示（不需要 logcat）：

```
数据加载成功
items=18  weapons=5  ammo=5  armor=3  loot=3
```

如果显示「数据校验失败」或「读取 xxx 失败」，说明数据或 StreamingAssets 复制有问题，屏幕会列出具体项。

这表示：C# 数据层、JSON、交叉引用校验、Android 文件读取路径**全部在手机上跑通了**。

---

## 5. 工作流参数说明

| 参数 | 值 | 说明 |
|---|---|---|
| `unityVersion` | `auto` | 读 `ProjectSettings/ProjectVersion.txt`；镜像不存在时改成明确版本号 |
| `targetPlatform` | `Android` | — |
| `buildMethod` | `BuildScript.BuildAndroid` | 见 [BuildScript.cs](../Assets/Editor/BuildScript.cs) |
| `androidExportType` | `androidPackage` | 产出 APK；要 AAB 改 `androidAppBundle` |

构建脚本会自动处理两件事：

1. `Assets/Scenes/Main.unity` 不存在时自动生成（相机 + 灯光 + `GameDataBootstrap`）。
2. 输出到 `build/Android/tarkovlike.apk`。

---

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `No valid Unity license` | secrets 未配或许可证过期 | 重跑第 2 节 |
| `Unity version not found` | GameCI 镜像没有该版本 | 把 `unityVersion: auto` 改成具体版本（如 `6000.0.32f1`） |
| 构建超时 | IL2CPP 首次构建慢 | 调大 `timeout-minutes`，或接受缓存第二次变快 |
| 下载的 APK 装不上 | 未允许未知来源 | 设置里允许，或用 adb |
| 屏幕显示 `items=0` | StreamingAssets 未打进包 | 确认 `Assets/StreamingAssets/GameData/*.json` 已提交 |
| PR 里构建失败 | fork 的 PR 拿不到 secrets | 私有分支/手动触发 |
| 免费额度不够 | Actions 分钟数 | 只保留手动触发，或升级套餐 |

---

## 7. 边界

- 这是 **debug 签名** APK，仅用于验证，不能上架。M4 再配 keystore + Release 构建。
- 云端构建不覆盖手感：触屏、后坐力、帧率仍按 [03-真机测试清单](03-真机测试清单.md) 实机验收。
- 首次构建会下载 Unity 镜像层，通常 15~40 分钟；之后有缓存会快很多。
